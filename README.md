## Featured projects

### [Mars Rover Research Assistant](projects/mars-rover-rag-assistant/README.md)
A local, citation-first RAG prototype over three public NASA rover reports. Hybrid BM25 and semantic retrieval found the expected report page in the top five for **8/8** benchmark questions (semantic-only: **5/8**). Generated-answer correctness has not been benchmarked; local generation is optional and uses Ollama/Qwen3 1.7B.

### [Hybrid Comment Moderation](projects/hybrid-comment-moderation/README.md)
A six-label Jigsaw toxicity classifier using word and character TF-IDF with Logistic Regression. On a held-out 6,000-row test split, macro F1 was **0.5844** and micro F1 **0.7220**. Borderline cases are routed for human review; this is an educational prototype, not an automatic enforcement system.

### [Person detection and restricted-area alert prototype](https://github.com/harshV264/detection-Model)
A Python computer-vision prototype combining YOLOv8 person detection, DeepSORT tracking, and a boundary-crossing alert. Review that repository's current code and limitations before using its experimental gender-classification component.
